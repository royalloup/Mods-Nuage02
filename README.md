# Mods PAYDAY 2 — Nuage 02

## Contenu du repo

| Fichier | Description |
|---|---|
| `WSOCK32.dll` | SuperBLT — requis pour charger les mods |
| `[MOD] Exorciste.tar.gz` | Trainer complet — Card Spoofer actif en solo ET multi |
| `Mods-Nuage02-Complet.tar.gz` | Pack HUD Exorciste + Extra Heist Info + patch compatibilité |

---

## Étape 1 — Installer SuperBLT

SuperBLT est obligatoire pour faire fonctionner tous les mods.

1. Télécharge `WSOCK32.dll` depuis ce repo
2. Colle-le directement dans le dossier racine de PAYDAY 2 :
   ```
   Steam/steamapps/common/PAYDAY 2/
   ```
3. Lance le jeu — SuperBLT va se configurer automatiquement au premier démarrage

---

## Étape 2 — Installer [MOD] Exorciste (Trainer)

1. Télécharge `[MOD] Exorciste.tar.gz`
2. Extrais l'archive (avec 7-Zip ou WinRAR)
3. Copie le dossier `[MOD] Exorciste` dans :
   ```
   Steam/steamapps/common/PAYDAY 2/mods/
   ```
4. Le dossier doit s'appeler exactement `[MOD] Exorciste`

**Fonctionnalités incluses :**
- Card Spoofer activé en **solo ET multijoueur** (drop toujours un coffre ou drill)
- DLC Unlocker, AimBot, XRay, NoClip, SpawnMenu, et bien plus
- Auteur : **Nuage 02**

---

## Étape 3 — Installer le pack HUD + Extra Heist Info (optionnel)

1. Télécharge `Mods-Nuage02-Complet.tar.gz`
2. Extrais l'archive
3. Copie les dossiers dans :
   ```
   Steam/steamapps/common/PAYDAY 2/mods/
   ```

**Contenu du pack :**
- **Exorciste HUD** — HUD amélioré
- **Extra Heist Info** — informations supplémentaires en mission
- **Patch de compatibilité** — les deux mods fonctionnent ensemble sans conflit
